ATLAS 需求规范化 · 便携版 v3.3
============================

一、运行条件
  - Windows 10 / 11
  - 安装 Node.js LTS（https://nodejs.org/），安装时保持默认选项
  - 不需要 npm install，本项目零依赖

二、启动
  双击「启动.cmd」。
  浏览器会自动打开 http://127.0.0.1:43125；没有自动打开就手动输入这个地址。

三、停止
  关闭黑色窗口，或在窗口里按 Ctrl+C。

四、端口被占用
  如果提示“端口 43125 已被占用”，在窗口里执行：
      set PORT=43126
      node server.mjs

五、数据位置
  data\<身份码>\<产品名>.json
  复制整个文件夹即可带走全部数据；删掉某个身份码文件夹 = 删除该身份及其产品。

六、AI 配置
  整合包根目录的 ai-config.env（../ai-config.env）保存 API Key，
  只在服务端读取，不会下发到浏览器；第一页 / 第二页 / backend 共用这一份，改一次两端同时生效。
  注意：本压缩包内包含你的 Key，不要转发给不信任的人。

七、让同一局域网的其他设备访问这台电脑
  在窗口里执行：
      set HOST=0.0.0.0
      node server.mjs
  然后用这台电脑的局域网 IP 访问，例如 http://192.168.1.10:43125
  首次访问会弹 Windows 防火墙提示，选“专用网络”并允许。

八、关于刷新与关闭
  刷新页面不会清空进度：身份码、已选条目、当前步骤都会保留。
  关闭标签页或浏览器窗口后重新打开，才会清空本次进度并回到身份码入口。
  点「退出登录」会立刻清空本次进度（已保存的产品不受影响）。

九、进入下一阶段（第二页）
  三个问题确认并保存后，摘要卡点「进入下一阶段」。
  第一页把整份 JSON 交给 next.html，第二页据此打开方案配置：
  - 左侧是用户自配器：按模块 / 零件类型展开 10 个型号（基础四款：标准 / 轻量 / 增强 / 旗舰，
    加两个厂家各 3 款），卡片上直接写单价、重量和性能分，点「加入」写入当前方案；
  - 上方两个入口：从系统推荐开始自配、从零开始自配；每点一次，右侧新增一列；
  - 中间是系统推荐 + 用户自配的对比矩阵，标题位置直接列出第一页的约束（4 条硬约束 + 1 条软约束），
    逐条悬停（或键盘聚焦）可看条件、系统推荐值和是否达标；
  - 「系统推荐」不是固定的 CSV 基线：它用「极速引擎」（多起点爬山）在 280 个型号里搜索——
    先分别摆出全标准件 / 全最低价 / 全最轻 / 全最高性能 / 全最低风险五套，各按当前评分权重
    一件一件挑「涨分最多」的替换，最后取分数最高的那一路（评分区顶部写着是哪个起点赢的）；
    换掉的格子前面有青色圆点；拖动评分权重会按新权重重算推荐；
  - 零件列约占表宽 1/4（140–240px 自适应），模块名左对齐；用户方案按 1/2/3 顺连，删掉中间一列会自动补号；
  - 悬停零件名看厂家、型号、3 个核心参数、性能分与单价 / 重量 / 交期；
  - 所有用户方案的 28 个零件都填满后，「开始对比」才可用；
  - 不满足第一页硬条件的方案，列名旁会出现「!」，悬停可看具体条件；
  - 对比后下方出现「自定义加权评分」：成本 / 重量 / 性能 / 风险 / 约束五个维度可拖权重
    （交期已并入风险：风险等级占 60%、交期档位占 40%），
    硬约束不满足封顶 20 分、软约束不满足封顶 60 分；
  - 右侧是零件详情：顶部一张该零件类别的示意图（28 类各一张，同类 10 个型号共用），
    下面是厂家 / 型号 / 核心参数 / 性能分 / 单价 / 重量 / 交期 / 风险分。
  第二页只有两个页签：方案对比、交付排期（原来的「结构爆炸」已删掉）。

  交付排期（第二个页签）：
  - 按当前得分最高的方案里 28 个零件的交期倒排：7 组采购 → 轴系组装 → 电气总装 → 整机检查，
    AI 三条任务（到料预测 / 装配排程 / 视觉检测）并行，共 13 项任务、3 人 + AI；
  - 资源调平：采购条只画「下单那半天」，供应商交期画成浅色虚线轨道 + 到料菱形；
    7 张采购单按半天一个工位排开，同一时刻周予手上只有一单（绝不重叠），一天最多两单；
    总时长和「全部第 0 天下单」完全一致（演示里仍是 48 天），
    同一人重叠 0 处、同日开工最多 2 项、同日收尾最多 1 项，这三项写在「人员协作」卡底部；
  - 只填两个日期：起始日期、终止日期。条形位置由交期算出，不会跟着日期变；
    窗口比计划短会把任务压到窗口外并标红，点「按交期自动排」可一键排满；
  - 上半屏甘特图：4 条泳道（AI / 采购·周予 / 装配·陈屿 / 检查·苏航）、顶部月份与日期刻度、
    周末底纹、预警线（节点 / 预警 / 延期三级）；
  - 下半屏流程图：采购 7 个节点先汇合成两路，再进轴系组装、电气总装、整机检查；AI 单独一条带；
  - 点甘特条会闪对应的流程节点，反过来点节点也会闪条形；图例里点泳道可临时隐藏该人的任务；
  - 下面三张卡：周期风险（预警线与日期）、人员协作（每人任务数、跨度与调平指标）、排期口径（四条规则）；
  - 「排期基准」可切换系统推荐或某个用户方案，换方案即按新方案的交期重排。
  交接内容只有同一身份码能读回，12 小时后自动过期。

十、表1（预设零件表）
  位置：presets\table1.json，页面右下角「表1」链接可查看全文。
  目前只有 h3 手持云台一种整机，下分 7 个模块（h3-cam 等），每个模块 4 个零件（h3-cam-01 等）。
  AI 只能从这张表里选 code，不能自造零件；L4（材料/工艺级）暂时停用。
  修改规则：直接改 table1.json 后重启服务即可，问答流程和前端不用改；
  新增商品类型时复制一份 productTypes 条目，按同一编码规则补 modules 与 parts。
